# Car rental

The practice project of the Git play: two people, one program, one history.

- `price.py` computes what a rental costs: 60 CHF per day, 10% off from 7 days on.
- `contract.py` prints the price of a 7-day rental.

To start the play, Partner A opens https://github.com/sef-hs26/git-together and clicks
**Use this template**, then **Create a new repository** (Scene 1.1). From there, follow the guide
"Git together: the car rental" scene by scene.
